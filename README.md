# 台股量化多因子投資策略研究系統 (TWSE Quant Alpha vs 0050)

本專案旨在研究並實作一套超越 **0050 (元大台灣50 ETF)** 的台股量化選股與資產配置策略體系。透過整合 GitHub 熱門開源量化研究（包含 FinLab 經典營收動能、FinMind 三大法人籌碼、多因子動量輪動），並結合台灣證券市場專屬特性（強制每月 10 號前公告月營收、投信認養與作帳效應），建構具備全天候抗跌與進攻能力的量化多因子模型。

---

## 🌟 核心策略設計架構

系統實現三組風格鮮明的量化選股策略，並以 **0050 Buy & Hold** 作為基準進行同場對決（2020 ~ 2026 年近 5 年多週期）：

### 1. 策略 A：營收爆發突破策略 (`Strategy A: Revenue Growth Breakout`)
* **核心邏輯**：月營收為台灣市場獨有的全球最高頻基本面數據。當個股月營收創近 12 個月新高或年增率 (YoY) 呈現爆發性成長，且股價站在 20 日均線（月線）之上呈現技術突破時，往往具有持續的盈餘驚喜與爆發力。
* **選股規則**：
  1. 流動性過濾：近 20 日均成交額 $\ge 3,000$ 萬新台幣（排除殭屍股與流動性陷阱）。
  2. 技術突破：收盤價 $> 20\text{MA}$。
  3. 因子排序：營收 YoY 年增率與近 3 個月營收平均動能排名前 15 檔等權重買進。

### 2. 策略 B：投信法人籌碼共振策略 (`Strategy B: Institutional Trust Momentum`)
* **核心邏輯**：國內投信基金在台股中小型黑馬股具備極強的定價權與抱團作帳效應。追蹤投信連續買超力道（買超佔成交量比重）並輔以技術動量，能有效搭上法人主升段便車。
* **選股規則**：
  1. 流動性過濾：近 20 日均成交額 $\ge 3,000$ 萬新台幣。
  2. 技術面：收盤價 $> 20\text{MA}$。
  3. 籌碼排序：近 20 日投信買超佔成交量比重 (Trust Net Buy Ratio) + 外資買超支持度綜合打分，精選前 15 檔等權重配置。

### 3. 策略 C：綜合多因子防禦增強旗艦策略 (`Strategy C: Ensemble Multi-Factor Defensive`)
* **核心邏輯**：單一因子容易在不同牛熊市遭遇風格逆風。綜合旗艦策略結合「基本面營收爆發 (40%) + 籌碼面法人鎖碼 (30%) + 技術面動量多頭 (30%)」，並外掛「0050 季線宏觀風控保護」：
  - **進攻模式 (0050 > 60MA 季線)**：大盤處於多頭循環，100% 倉位滿載進攻，捕捉中小型強勢 Alpha。
  - **防禦模式 (0050 < 60MA 季線)**：大盤處於空頭或系統性回檔（如 2022 年大跌），主動降槓桿至 20% 持股，80% 轉為現金避險，鎖定前期利潤並大幅降低最大回撤 (MDD)。

## ⚙️ 回測與交易摩擦模型

為了避免「紙上富貴」，本回測引擎嚴格模擬真實台股交易環境成本：
* **換股頻率**：每月調倉一次（固定於每月 11 號後的第一個交易日，確保全市場最新月營收已全數公告完畢）。
* **券商手續費**：買賣各 $0.1425\% \times 50\% = 0.07125\%$（實戰常見 5 折折讓）。
* **證券交易稅**：賣出時課徵 $0.30\%$。
* **雙向滑價摩擦**：買賣各預估 $0.10\%$ 滑價成本。
* **單趟進出總摩擦成本**：約 $0.6425\%$。

## 📂 專案目錄結構

```
TWSE_Research/
├── README.md               # 專案詳細說明與架構手冊
├── requirements.txt        # 依賴套件清單 (yfinance, finmind, pandas, matplotlib)
├── run_backtest.py         # 一鍵回測執行腳本
├── src/
│   ├── data/
│   │   ├── universe.py     # 台股代表性選股池 (涵蓋半導體、AI、重電、航運、金融等)
│   │   └── fetcher.py      # 日 K 線、月營收、法人買賣超抓取與本地快取
│   ├── factors/
│   │   └── factor_builder.py # 流動性濾網、營收YoY、投信籌碼、動量指標計算
│   ├── strategies/
│   │   ├── strategy_a_revenue.py       # 策略 A：營收爆發突破
│   │   ├── strategy_b_institutional.py # 策略 B：投信籌碼共振
│   │   └── strategy_c_multifactor.py   # 策略 C：綜合多因子防禦旗艦
│   ├── backtest/
│   │   ├── engine.py       # 向量化與事件驅動月調倉回測引擎
│   │   └── metrics.py      # CAGR、MDD、Sharpe、Calmar、勝率、Alpha/Beta 計算
│   └── visualize/
│       └── report.py       # 淨值走勢圖、水下回撤圖、年度報酬柱狀圖與 Markdown 報告生成
└── reports/                # 回測成果圖表與彙整報告輸出目錄
```

---

## 🚀 快速開始

### 1. 安裝環境依賴
```powershell
pip install -r requirements.txt
```

### 2. 執行回測評估
```powershell
python run_backtest.py --start 2020-01-01 --end 2026-09-30 --capital 1000000
```

### 3. 查看產出
回測完成後，將在 `reports/` 目錄自動產生：
- `backtest_summary.md`：績效對比矩陣與年度報酬分析
- `backtest_comparison.png`：累積淨值曲線、回撤曲線與歷年報酬圖
